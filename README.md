# PalindromZahlen

Suche "Palindrom-Zahlen",
das heißt Zahlen, die addiert mit ihrer Spiegelzahl von vorne wie von hinten gleich sind.

## Rechenregel

Suche zu einer Zahl ihre Palindrom-Zahl,
indem du zur Basiszahl ihre Spiegelzahl addierst.

        Beispiel:

         12 -->  12 +  21 =  33 ✅️

         83 -->  82 +  28 = 110 🔄
        110 --> 110 +  11 = 121 ✅️
